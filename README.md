# OpenCV-cam-check-with-4-different-filters
A small open cv project made and then we can switch between filters.

In total there are 4 modes: normal, blur, edges(canny), grayscale

How the output will look?
Initially we will be normal mode and then the other modes can be accessed by pressing keys for the respective mode:
blur - b
grayscale - g
edges - e

then we can go back to normal mode again by clicking the key n which is for normal mode.

Also when you are in the current mode,a text of what mode you are in is also added in a specific color.

Blur - red 🔴
Grayscale - gray ⚫
Edges - white ⚪
Normal - green 🟢
